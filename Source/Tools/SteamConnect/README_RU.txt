ROOM CHAT AUTO

Теперь relay-адрес руками вводить не нужно.

ПЕРВЫЙ ЗАПУСК
1. Распакуй ZIP в отдельную папку.
2. Двойной клик START.bat.
3. Если настройки еще нет, автоматически запустится SETUP.
4. Выбери:
   1 = Yandex Cloud
   2 = Cloudflare
   3 = оба (Yandex основной, Cloudflare резервный)
5. Один раз пройди авторизацию выбранного облака.
6. После развертывания URL автоматически сохранится в relay-config.json.

ОБЫЧНЫЙ ЗАПУСК
Просто START.bat.
Программа сама проверит настроенные relay и выберет рабочий.
В браузере появится QR для телефона.

ВАЖНО
- Yandex и Cloudflare хранят разные списки комнат. Если программа переключилась
  с одного облака на другое, комнаты из первого облака во втором не появятся.
- Это тестовый прототип без паролей и аккаунтов.
- Для Yandex нужен активный billing/cloud/folder. SETUP может установить yc CLI
  на Windows, но вход в аккаунт и выбор каталога требуют твоего подтверждения.
- Cloudflare SETUP использует Wrangler и откроет вход в Cloudflare.
