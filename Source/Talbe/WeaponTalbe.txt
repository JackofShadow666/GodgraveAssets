# ПОЛЯ (по порядку):
#   key            — внутренний идентификатор вида оружия (sword/dagger/...)
#   name           — отображаемое имя (для UI/HUD), кириллица допустима
#   category       — папка спрайтов на сервере (Source/Weapon/<category>/...):
#                    "sword" -> Source/Weapon/Sword/, "knife" -> Source/Weapon/Knife/
#   throwSpeed     — начальная скорость брошенного оружия (px/кадр). Определяет
#                    дальность броска — чем больше, тем дальше летит.
#   scale          — базовый масштаб клинка относительно эталонного меча (1.0 = как меч)
#   dmgBase        — базовый урон брошенного оружия при попадании (константа)
#   dmgPerSpeed    — множитель урона за скорость полёта (урон = dmgBase + скорость*dmgPerSpeed)
#   maxDmgPercent  — потолок урона за ОДНО попадание, в долях от ТЕКУЩЕГО HP цели
#                    (0.20 = не больше 20% текущего HP за раз, даже при большой скорости)
#   spinMin        — минимальная угловая скорость вращения в полёте/при отскоке (рад/кадр)
#   spinMax        — максимальная угловая скорость вращения в полёте/при отскоке (рад/кадр)
#
# key    |name   |category|throwSpeed|scale|dmgBase|dmgPerSpeed|maxDmgPercent|spinMin|spinMax
