# Правила для `src`

- Сначала читай `src/MAP.md`, потом открывай только целевой модуль.
- Не открывай `Build.html`, если задача не про DOM, CSS, overlay или порядок загрузки скриптов.
- Для логических правок почти всегда достаточно 1-2 файлов из `src/` и точек вызова в `src/main.js`.
- Если поведение отличается только в онлайне, обязательно проверяй `src/network/net.js`.
- Если поведение отличается только в локальном PvP, проверяй вместе `src/input/player-controls.js` и `src/combat/factions.js`.
- Если поведение отличается только на телефоне, проверяй `src/ui/mobile.js`.
- Не читай `Build.standalone.html` для обычных задач.
- При review или debug сначала перечисли релевантные файлы, затем работай только в их границах.

## Быстрые маршруты

- Бой: `src/combat/*`, затем `src/main.js`
- ИИ: `src/ai/ai.js`, затем оружие или `src/main.js`
- HUD: `src/ui/hud.js`, затем режимные интеграции
- Сеть: `src/network/net.js` и точка вызова из gameplay
- Мобильное управление: `src/ui/mobile.js`
